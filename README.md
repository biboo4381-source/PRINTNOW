# PRINTNOW: Upload Website

Customer-facing website for PRINTNOW self-service printing kiosks. Customers upload documents, choose print settings, complete a simulated (demo) QRIS payment, and receive a collection code to print at a PRINTNOW kiosk.

**Status:** Phase 1, architecture proposal waiting for approval.
See [docs/ARCHITECTURE_PROPOSAL.md](docs/ARCHITECTURE_PROPOSAL.md).

Planned stack: Next.js (TypeScript) on Vercel, Neon Postgres, Vercel Blob.
